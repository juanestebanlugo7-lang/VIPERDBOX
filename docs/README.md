# Viperdbox
ViperdBox es una aplicacion web social para descubir, calificar, hacer reseñas y organizar tus peliculas muy inspirada en Letterboxd. Permite a los usuarios

- Registrarse e iniciar sesión de forma segura .
- Buscar películas en tiempo real usando la API de TMDB (The Movie Database).
- Calificar peliculas de 1 a 10 estrellas y escribir reseñas.
- Organizar tus peliculas en listas personalizadas: favoritas, pendientes y vistas.
- Ver un dashboard con las estadisticas de la comunidad.
- Interactuar con otras reseñas en forma de (likes) y poder ver perfiles de otros usuarios.
- Administar el sistema (Moderar las reseñas)cuando tienes el rol de administrador.
